# ترجملي (Tarjimli)

تطبيق ويب عربي يترجم الفيديوهات (ومنها ريلز إنستغرام بعد تنزيلها) إلى العربية بطريقتين:
- **ترجمة مكتوبة**: ترجمة عربية مدمجة في الفيديو مع الإبقاء على الصوت الأصلي (ويُعطيك أيضاً ملف SRT/VTT).
- **دبلجة صوتية**: صوت عربي مولَّد بالذكاء الاصطناعي مُزامَن مع الفيديو، مع خيار خفض الصوت الأصلي أو كتمه.

## كيف يعمل
1. FFmpeg يستخرج الصوت من الفيديو.
2. OpenAI Audio Transcription (`whisper-1`) يحوّل الكلام إلى نص بتوقيتات.
3. OpenAI (`gpt-4o-mini`) يترجم النص إلى العربية.
4. للدبلجة: OpenAI Text-to-Speech (`gpt-4o-mini-tts`) يولّد صوتاً لكل مقطع، ويُسرَّع قليلاً عند الحاجة ليتناسب مع التوقيت، ثم يدمجه FFmpeg مع الفيديو الأصلي (الصورة تبقى كما هي بلا إعادة ترميز).
5. للترجمة المكتوبة: تُحرَق الترجمة على الفيديو (بخط Noto Sans Arabic).

الملفات المرفوعة والمؤقتة تُحذف بعد المعالجة، والمخرجات تُحذف تلقائياً بعد ساعة.

## ملاحظة عن روابط إنستغرام
تنزيل الفيديو من رابط إنستغرام مباشرةً غير موثوق وكثيراً ما يُحظر، لذلك **الرفع هو الطريقة المدعومة**. نزّل الريل على هاتفك ثم ارفعه من «اختر الفيديو». حقل الرابط موجود في الواجهة ويشرح هذا للمستخدم، ولا يُنزّل شيئاً.

## التشغيل محلياً
```bash
# يلزم تثبيت Python 3.11+ و FFmpeg (مع خط عربي مثل Noto Sans Arabic)
pip install -r requirements.txt
export OPENAI_API_KEY="sk-..."      # على ويندوز: set OPENAI_API_KEY=sk-...
uvicorn app:app --port 8000
```
ثم افتح http://localhost:8000

أو عبر Docker:
```bash
docker build -t tarjimli .
docker run -p 10000:10000 -e OPENAI_API_KEY="sk-..." tarjimli
```
ثم افتح http://localhost:10000

## النشر على Render والحصول على رابط HTTPS
1. أنشئ حساباً على https://github.com وأنشئ مستودعاً **خاصاً** جديداً، وارفع إليه محتويات هذا المجلد (ملف `.gitignore` يمنع رفع `.env`).
2. أنشئ حساباً على https://render.com واربطه بحساب GitHub.
3. من لوحة Render: **New +** ثم **Web Service** ثم اختر المستودع.
4. اختر **Language: Docker** (سيكتشف `Dockerfile` تلقائياً). اختر خطة **Starter** على الأقل: الخطة المجانية (512 ميغابايت) غالباً لا تكفي لمعالجة الفيديو وتنام عند الخمول.
5. في قسم **Environment Variables** أضف:
   - `OPENAI_API_KEY` = مفتاحك من https://platform.openai.com/api-keys
6. اضبط **Health Check Path** على `/api/health` ثم اضغط **Create Web Service**.
7. بعد انتهاء البناء (عدة دقائق) يظهر رابطك بصيغة `https://tarjimli-xxxx.onrender.com` وهو HTTPS جاهز.

يمكنك أيضاً استخدام الملف `render.yaml` عبر **New +** ثم **Blueprint**؛ سيطلب منك Render إدخال قيمة `OPENAI_API_KEY` أثناء الإعداد.

## حماية مفاتيح API
- المفتاح يُقرأ من متغير البيئة `OPENAI_API_KEY` في الخادم فقط، ولا يوجد أي مفتاح في HTML أو JavaScript.
- لا تضع المفتاح في الكود أو في GitHub. استخدم **Environment Variables** في Render فقط.
- للتشغيل المحلي انسخ `.env.example` إلى `.env` (الملف مستثنى من Git و Docker).
- حدّد سقف إنفاق شهرياً لمفتاحك من لوحة OpenAI (Usage limits)، فكل عملية ترجمة أو دبلجة تستهلك رصيداً.
- إن كشفت المفتاح بالخطأ، احذفه من لوحة OpenAI وأنشئ غيره فوراً.

## متغيرات اختيارية
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MAX_UPLOAD_MB` | 100 | أقصى حجم للفيديو |
| `MAX_DURATION_SECONDS` | 600 | أقصى مدة للفيديو |
| `MAX_CONCURRENT_JOBS` | 1 | عدد المعالجات المتزامنة |
| `OPENAI_TRANSLATE_MODEL` | gpt-4o-mini | نموذج الترجمة |
| `OPENAI_TTS_MODEL` | gpt-4o-mini-tts | نموذج توليد الصوت |
| `OPENAI_TRANSCRIBE_MODEL` | whisper-1 | يجب أن يدعم `verbose_json` لتوقيتات المقاطع |

## قيود مهمة
- حالة المهام محفوظة في ذاكرة الخادم (عملية واحدة). إن أُعيد تشغيل الخادم أثناء المعالجة تُفقد المهمة الجارية.
- الفيديوهات الطويلة تحتاج وقتاً أطول وتكلفة أعلى؛ الحد الافتراضي 10 دقائق.
- جودة المزامنة تعتمد على طول الجملة العربية مقابل الأصلية؛ يُسرَّع الصوت حتى 1.6 مرة عند الحاجة.
